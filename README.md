# 좋음PT 센터 통합 관리

직원·강사용 센터 관리 프로그램 (예약·출석, 회원·수강권, 수업일지, 매출, 공지·할 일).

- 화면: `index.html`, `style.css`, `js/` — 빌드 없이 바로 열리는 정적 웹페이지
- 데이터: Supabase (`js/config.js`의 주소·publishable 키)
- DB 구조와 권한 규칙: `supabase/schema.sql` (Supabase SQL Editor에서 실행)

## 권한
- 맨 처음 가입한 계정 = 관리자. 그 뒤 가입한 계정은 **승인 대기** → 관리자가 *직원 관리*에서 강사로 바꿔야 사용 가능
- 관리자: 모든 매출·결제를 봄 / 강사: 본인에게 잡힌 매출만 봄 (DB 권한 규칙으로 막혀 있음)

## 체험 모드
주소 뒤에 `?demo=1` 을 붙이면 브라우저에만 저장되는 체험 모드로 열림.
